## 本次更新

- 关闭窗口时选择“后台运行”后，会在当前应用进程内记住该选择。
- 同一进程中从系统托盘或二次启动重新打开窗口后，再次点击关闭按钮会直接转入后台，不再重复弹出选择框。
- 完全退出应用并重新启动后，关闭选择会自动清空，首次关闭时重新显示确认弹窗。
- 关闭选择只保存在 Rust 进程内存中，不写入配置文件或浏览器存储；WebView 重建不会丢失该选择。
- 自动隐藏失败时会恢复显示关闭确认弹窗，避免窗口关闭操作无反馈。

## 构建产物

- Windows x64 NSIS 安装程序（`.exe`）
- macOS Universal DMG（Apple Silicon + Intel）

本版本由 GitHub Actions 在 Windows 与 macOS runner 上分别执行前端检查、Rust 单元测试和 Tauri 打包后发布。
